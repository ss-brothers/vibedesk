# Contributing to VibeDesk

First off, thank you for considering contributing to VibeDesk! 🎉 
This project is built for the community, to provide a beautiful, calming, and aesthetic workspace for everyone.

## 🛡️ Core Philosophy & Strict Rules

To keep the `main` branch safe and aligned with our vision, we have very strict rules about what can be added to VibeDesk. 

**What we LOVE to see:**
- ✅ New aesthetic themes (Nature, Calm, Cinematic, Cultural).
- ✅ Bug fixes, UI improvements, and performance optimizations.
- ✅ Integration of open-source/CC0 HTML5 mini-games.
- ✅ Addition of CC0 ambient/lo-fi music tracks and video loops.

**What is STRICTLY PROHIBITED:**
- ❌ **NSFW Content:** Absolutely no nudity, gore, or sexually explicit content.
- ❌ **Political Content:** No political flags, slogans, or controversial themes.
- ❌ **Religious Bias:** VibeDesk celebrates culture and architecture, but we avoid promoting specific religious agendas. Keep it culturally neutral and respectful.
- ❌ **Copyrighted Material:** Do not submit PRs with images, videos, or music that you do not have the rights to use. Use Unsplash, Pexels, Pixabay, or CC0 assets only.

Pull Requests violating these rules will be immediately closed and the contributor may be blocked.

## 🛠️ How to Contribute

1. **Fork the Repository:** Create your own fork of the project.
2. **Create a Branch:** Create a branch for your feature (`git checkout -b feature/amazing-theme`).
3. **Make Changes:** Add your theme to `src/config/themes.ts` (or use the generator script `scratch/gen_themes.js`).
4. **Test Locally:** Ensure your changes build successfully (`npm run build`) and look good on mobile and desktop.
5. **Submit a Pull Request:** Open a PR against the `main` branch with a clear description of your changes and links to the CC0 assets you used.

## Adding a New Theme

If you are adding a new theme, make sure you provide:
- High-quality Unsplash Image ID.
- Seamless looping video URL (CC0).
- Appropriate Google Font mapping in `globals.css`.
- Logical tags for filtering.

Thank you for helping make VibeDesk the ultimate aesthetic workspace!
