# VibeDesk

VibeDesk is an open-source, beautifully crafted "Aesthetic Productivity & Lofi Workspace" built with Next.js and Tailwind CSS. 
It provides users with 70+ immersive environments (Themes) to focus, breathe, play, and relax. 

### 🚀 Live Preview: [vibedesk-for-fun.vercel.app](https://vibedesk-for-fun.vercel.app/)

Whether you want to study in a rainy Tokyo cafe, survive a zombie apocalypse, or relax on the beaches of Goa, VibeDesk has a vibe for you.

![VibeDesk Preview](https://images.unsplash.com/photo-1519681393784-d120267933ba?auto=format&fit=crop&w=1920&q=80)

## Features

- **74 Unique Themes:** Ranging from Indian States & Union Territories to Global Nations, Cyberpunk, Goth, and Lofi aesthetics.
- **Dynamic Fonts & Colors:** Every theme has its own distinct typography (20+ Google fonts) and color palette.
- **Immersive Modes:** Toggle between live Video backgrounds, high-res Images, or minimalist Gradients.
- **Focus Tools:** Integrated Focus Timer, Breathing Exercises, and Ambient Music.
- **Mini-Games:** Embedded HTML5 open-source mini-games for quick breaks.
- **Light & Dark Mode:** Adapts to your system or preference.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Fonts:** Next/Font (Google Fonts)

## Running Locally

1. Clone the repository:
   `ash
   git clone https://github.com/ss-brothers/vibedesk.git
   cd vibedesk
   `

2. Install dependencies:
   `ash
   npm install
   `

3. Run the development server:
   `ash
   npm run dev
   `

4. Open http://localhost:3000 with your browser.
